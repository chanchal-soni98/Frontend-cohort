# 🛍️ Product Listing with Favorites, Search & Sorting

This is a simple React application that displays a list of products fetched from a JSON file. Users can search for products by title (case-insensitive), sort them by price (ascending or descending), and add products to a list of favorites stored in localStorage.

## 🚀 Getting Started

# Install dependencies
npm install

# Start the development server
npm run dev
